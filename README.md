> **CRITICAL SAFETY: BATTERY POWER ONLY**
> This EEG circuit must ONLY be powered by a single 9V battery. NEVER connect this device to any mains-powered equipment or power supplies. Proper galvanic isolation is mandatory for safety when connecting electrodes to a human subject.

## Overview

This repository contains DIY EEG circuit designs specifically constrained to use a single TL074CN op-amp and a single 9V battery. These designs prioritize simplicity, safety, and performance for low-cost neurofeedback experiments.
