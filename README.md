## Safety Warning
> [!WARNING]
> **Battery Power Only!** This circuit must be powered by a single 9V battery to ensure galvanic isolation and user safety. Never connect this circuit to a mains-powered power supply or any device that is connected to the wall outlet while you are attached to the electrodes.

## Introduction
This repository contains DIY EEG circuit designs specifically constrained to use a single TL074CN op-amp and a single 9V battery.
