# Machine Learning

This repository contains a minimalist DIY EEG (electroencephalogram) circuit design optimized for simplicity and safety. The design utilizes a single TL074CN quad op-amp and is powered by a single 9V battery, making it an accessible entry point for bio-signal amplification projects.
