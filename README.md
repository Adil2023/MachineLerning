# 🧠 MachineLerning: DIY EEG Circuit Designs

A collection of professional-grade, minimalist EEG circuit designs for real-time brain wave visualization.

## 🚀 Overview

This repository provides technical designs and assembly guides for building accessible EEG hardware using common components like the TL074 op-amp and 9V batteries.

## ⚠️ Safety First

**ELECTRICAL SAFETY IS MANDATORY.**
- Designs in this repository must **ONLY** be powered by batteries (e.g., 9V).
- **NEVER** connect electrodes or the circuit to mains-powered equipment without medical-grade isolation.
- Failure to follow safety protocols can result in serious injury or death.
