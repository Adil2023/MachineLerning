> **CRITICAL SAFETY NOTICE: BATTERY POWER ONLY**
> This device MUST be powered by a single 9V battery only. NEVER connect this circuit to a wall-powered power supply or any device connected to the mains (AC power) while attached to a human. Ensuring absolute galvanic isolation is mandatory to prevent lethal electric shock.

## Overview
This repository contains designs for a minimalist DIY EEG (Electroencephalogram) circuit. The architecture is specifically optimized for a single TL074CN quad op-amp and a single 9V battery, providing a high-performance, low-cost solution for brain-computer interface (BCI) experimentation.
