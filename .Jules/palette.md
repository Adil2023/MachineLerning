## 2024-05-09 - [UX in Documentation-Centric Repositories]
**Learning:** In repositories that lack a traditional software interface, the documentation (README.md) *is* the user interface. Micro-UX improvements should focus on instant project discoverability, clear safety warnings, and logical information hierarchy.
**Action:** When working on documentation-heavy projects, treat the README.md as the landing page and optimize for clarity and safety.
