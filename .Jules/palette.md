## 2025-06-14 - README as Primary UI
**Learning:** In documentation-centric repositories lacking a traditional software interface, the README.md acts as the primary user interface. Micro-UX improvements should prioritize information hierarchy, discoverability, and prominent safety warnings placed before technical details.
**Action:** Treat documentation-only projects with the same UX rigor as web apps, ensuring correct branding (no typos) and immediate visibility of critical safety information through standard callout syntax.
