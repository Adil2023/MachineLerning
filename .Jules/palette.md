## 2025-05-14 - Safety as UX in Hardware Documentation
**Learning:** In documentation-centric hardware projects, the README is the primary UI. Critical safety warnings are the most important UX elements as they protect the user. Placing them at the very top using high-visibility formatting (like `[!WARNING]`) ensures they are not missed before the user engages with the technical content.
**Action:** Always prioritize safety warnings at the top of the README for hardware projects involving human interaction or dangerous voltages.
