## 2024-05-22 - [Documentation as UI]
**Learning:** In documentation-centric repositories, the README.md acts as the primary user interface. Micro-UX improvements should prioritize information hierarchy, branding (e.g., correct spelling in headings), and prominent safety warnings placed before technical details.
**Action:** When working on hardware or documentation projects, treat the README with the same UX rigor as a GUI, ensuring critical safety information and professional branding are immediate and clear.
