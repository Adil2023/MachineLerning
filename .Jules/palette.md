## 2024-05-12 - README as the Primary UI in Documentation-Centric Repos
**Learning:** In repositories that lack a traditional software interface, the README.md serves as the primary user interface. Micro-UX improvements must focus on clear information hierarchy, discoverability through a Table of Contents, and the prioritization of high-stakes information like safety warnings.
**Action:** When working on documentation-only projects, treat the README.md as a landing page. Use visual separators, tables for specifications, and prominent callouts for safety or critical instructions.
