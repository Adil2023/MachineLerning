## 2025-05-14 - Documentation as the Primary UI
**Learning:** In repositories that lack a traditional software interface, the `README.md` serves as the primary User Interface. Micro-UX improvements in this context should prioritize information hierarchy, branding professionality (typo fixes), and the immediate visibility of critical safety warnings to establish trust and ensure safe usage.
**Action:** Treat README updates in doc-only repos with the same UX rigor as component updates, prioritizing safety callouts and professional branding to enhance user trust and accessibility.
