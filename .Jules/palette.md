# Palette's Journal

## 2025-06-13 - [Safety as UX]
**Learning:** In hardware projects involving human electrode connection (like EEG), safety information is the most critical UX element. Placing it prominently with high-visibility callouts prevents hazardous misuse and builds user trust.
**Action:** Always place 'Battery Power Only' and 'Galvanic Isolation' warnings at the top of the README using `[!WARNING]` syntax.
