## 2026-06-06 - Documentation as Primary UI
**Learning:** In minimalist or documentation-centric repositories, the README.md serves as the primary user interface. UX improvements should focus on information hierarchy, branding accuracy, and safety prominence.
**Action:** Prioritize correcting branding typos and placing critical safety warnings at the top of the README to establish trust and ensure user safety.

## 2026-06-06 - Contextual Relevance in UX
**Learning:** Adding domain-specific warnings (like hardware safety) to a project without clear context can be perceived as a hallucination or noise. UX improvements must be grounded in the visible scope of the repository.
**Action:** Always verify that enhancements, especially warnings or instructional changes, are directly supported by the existing codebase or project description to maintain credibility.
